# Shop with MySQL：台灣好物商場 v6.0.2 資料表 SQL

台灣好物商場（PHP + MariaDB，InfinityFree 主機）第一～六階段的資料表結構、預設資料與範例資料。版本 **6.0.2**（2026-11-23），已包含 6.0.1、6.0.2 的全部修改。

- 資料庫：MariaDB 10.5 以上（InfinityFree 為 11.4），也相容 MySQL 8
- 引擎與編碼：InnoDB、utf8mb4
- 時區：`+08:00`

## 檔案與匯入順序

在 phpMyAdmin 選好資料庫後，依下面順序匯入：

| 順序 | 檔案 | 必要性 | 內容 |
| --- | --- | --- | --- |
| 1 | `00_schema_full.sql` | 必須 | 一次建立全部 50 張資料表。只用 `CREATE TABLE IF NOT EXISTS`，重複匯入不會覆蓋既有資料。 |
| 2 | `01_default_data.sql` | 必須 | 會員等級門檻；三份公開文件範本（個資保護聲明、退換貨政策、購物須知）；4 家超商 × 8 縣市共 32 間模擬門市。 |
| 3 | `10_sample_data.sql` | 選用 | 測試與展示用範例資料。想從空的商場開始就不要匯入。 |

## 範例資料內容（`10_sample_data.sql`）

- 8 個帳號，密碼都是 `Shop@2026`：系統管理者 `admin@example.com`、3 位分工管理員、3 位一般會員、1 位待驗證會員
- 9 個商品、15 個規格（「台灣設計棉 T」為顏色 × 尺寸多規格商品，「鳳梨酥」為下架示範）
- 4 個分類、4 個標籤、2 條運費規則
- 363 筆會員行為事件（報表展示用）
- 1 則客服訊息，以及商店名稱、客服資訊、退貨地址等設定

> **上線前注意**：如果匯入了範例資料，請先修改 `admin@example.com` 的密碼，並把其他範例帳號停權或刪除。
